この index.html ファイルの中に、必要なものが全部まとめて入っているからです。

index.html ひとつの中に…
├── HTML  → 画面の枠組み（キャンバス）

└── JavaScript → ゲームの動き・当たり判定・描画すべて


外部のファイルや、インターネット接続も一切必要ありません。



どこに置いても動きます



| 場所 | 動くか |
|------|--------|
| パソコンのどこかのフォルダ | ✅ 動く |
| USBメモリに入れて別のパソコン | ✅ 動く |
| GitHubからダウンロードして開く | ✅ 動く |
| メールに添付して送る | ✅ 動く |



Python版（shot_game.py）との違い



| | Python版 | Web版（index.html） |
|---|---|---|
| 実行に必要なもの | Python・pygameのインストール | ブラウザだけ |
| 配布のしやすさ | 相手もPythonが必要 | ファイルを渡すだけ |

準備するもの



まず以下の情報が必要です。朝日ネットの会員証や登録メールを確認してください：

| 項目 | 内容 |
|---|---|
| FTPサーバー | ftp.asahi-net.or.jp など |
| ユーザー名 | 朝日ネットの会員ID |
| パスワード | 朝日ネットのパスワード |
| アップロード先フォルダ | public_html または www |



手順



ステップ１：FTPソフトを入れる（無料）



Cyberduck（サイバーダック） というソフトが Mac で使いやすいです。

https://cyberduck.io/download/


上のURLを開いて「Download」をクリックしてインストールしてください。



ステップ２：Cyberduck で朝日ネットに接続する



1. Cyberduck を開く
2. 「新規接続」をクリック
3. 以下を入力する：

接続方式：FTP
サーバー：ftp.asahi-net.or.jp
ユーザー名：あなたの会員ID
パスワード：あなたのパスワード


4. 「接続」をクリック



ステップ３：ファイルをアップロードする



接続できたら：

1. public_html または www フォルダを開く
2. shot-game というフォルダを作る
3. その中に index.html をドラッグ＆ドロップ

アップロードするファイルはここにあります：
/Users/nobuo/my-Claude-Project/shot-game/index.html




ステップ４：ブラウザで確認する



http://www.asahi-net.or.jp/~会員ID/shot-game/




まず朝日ネットのFTP情報を確認してみてください。 わからない場合は朝日ネットのサポートページや会員登録時のメールを探してみてください。情報が揃ったら次のステップをご案内します！
